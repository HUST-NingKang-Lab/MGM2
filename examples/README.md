# Python example

After installing the package and setting `MODEL_ROOT`:

```bash
python examples/embed_community.py --model-root "$MODEL_ROOT" --scale small
```

This example builds a constructed three-OTU community and prints the shapes of
its representations. For input tables, use `mgm2-embed --help`. For plots,
exports and sparse features, open the [tutorial](../notebooks/01_getting_started.ipynb).
