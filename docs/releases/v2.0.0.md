# MGM2 v2.0: community-level pretraining and interpretable microbial representations

Microbial General Model 2 (MGM2) brings microbial sequence identity, quantitative
abundance and community semantics into a shared representation of microbial
communities. Version 2.0 updates the pretraining formulation to reconstruct
microbial abundance from the community representation, alongside semantic
alignment. Four newly trained model scales are accompanied by a formal sparse
feature dictionary, a unified Python interface and an executable tutorial.

## Community-level reconstruction

In v2.0, the reconstruction decoder combines the community CLS representation
with the static identity of each queried OTU to predict its masked abundance.
This moves reconstruction supervision from individual contextual token states
to the community representation itself. CLS therefore participates directly in
both quantitative community reconstruction and semantic alignment.

The training objective combines abundance classification, high-abundance
regression and Qwen3 alignment. The semantic objective uses symmetric
multi-positive contrastive learning, treating communities with the same
normalized description as positives. Together, these objectives train a
community representation informed by microbial composition and descriptive
context.

## Four model scales, one interface

The model family provides community-level embeddings, contextual OTU states,
mean-pooled OTU representations and a 4,096-dimensional semantic projection.

| Model | Encoder parameters | Hidden dimension | Layers |
|---|---:|---:|---:|
| MGM2-Small | 4,076,352 | 224 | 6 |
| MGM2-Medium | 8,096,640 | 320 | 6 |
| MGM2-Large | 15,083,520 | 384 | 8 |
| MGM2-XLarge | 32,838,656 | 512 | 10 |

Checkpoints are distributed as `safetensors`, with architecture, selection epoch
and source-checkpoint identity recorded alongside each model. The installation
guide pins downloads to the matching v2.0 Hugging Face resource revision.

## Quantitative community representations

MGM2 represents each community with up to 768 microbial tokens, integrating
sequence identity with quantitative abundance. Pretraining combines
masked-abundance reconstruction and Qwen3 semantic alignment to connect
community composition with descriptive context. The model guide details the
preprocessing and training objectives.

The release includes NTv3-derived embeddings for 225,066 OTUs and taxonomic
fallback resources for 5,087 groups. Feature-resolution records accompany
exported community embeddings.

## Sparse features and interpretation

The formal sparse autoencoder maps MGM2-XLarge layer-10 OTU states into 4,096
features. Its checkpoint includes the affine normalizer, learned dictionary and
calibrated inference threshold.

The [SAE interpretation agent](https://github.com/LudensZhang/mgm2-sae-agent)
connects feature measurements to literature through an interpreter, an on-demand
researcher and an independent reviewer. Reusable evidence caches preserve
excerpts and source identifiers; compact structured handoffs reduce repeated
context transfer between roles.

## An installable research interface

- A `src/mgm2` package with grouped runtime, table, notebook and development dependencies.
- The `mgm2-embed` command for feature-by-sample CSV input and NumPy exports.
- An end-to-end notebook covering preprocessing, representations, CLI export and SAE features.
- Updated workflow figures, installation instructions and model documentation.
- Aggregate article benchmark tables for MGnify, FMT, drug perturbation and SAE analysis.

Install from the GitHub checkout:

```bash
python -m pip install '.[tables,hub,notebook]'
```

Follow the [installation guide](https://github.com/HUST-NingKang-Lab/MGM2/blob/main/docs/INSTALLATION.md)
to download the matching model resources, or start with the
[interactive tutorial](https://github.com/HUST-NingKang-Lab/MGM2/blob/main/notebooks/01_getting_started.ipynb).

## Validation

All four exported model scales reproduce their reference checkpoint outputs
under the tested CPU FP32 configuration. Fourteen tests cover preprocessing,
objectives, sparse features and public interfaces after installation outside
the source checkout. The tutorial executes with the Small encoder, XLarge
encoder and formal SAE, including a numerical comparison between CLI exports
and direct inference. Source and wheel distributions pass package metadata checks.
