# MGM2 v2.1.0: from microbial sequences to community representations

MGM2 v2.1.0 connects representative OTU and ASV sequences to community inference
through a dedicated legacy NTv3 encoding workflow.

## Sequence encoding

- Add `mgm2-encode-fasta` and the reusable `mgm2.sequences.encode_fasta` API.
- Use `InstaDeepAI/NTv3_650M_pre` with pinned weight and custom-code revisions.
- Export 1,536-dimensional sequence embeddings in the HDF5 format used by MGM2.
- Support local checkpoints, same-length batching and incremental output with
  sequence validation and encoder provenance.
- Keep sequence-encoder dependencies in the optional `ntv3` installation extra.

## Tutorials and documentation

- Add a FASTA-to-embedding notebook and sequence encoding guide.
- Make checkpoints, tutorials and the two input routes easier to find.
- Add concise contribution guidance and acknowledgements.

## Model bundle

The `v2.1.0` Hugging Face tag pairs this code release with the existing four
MGM2 checkpoints, embedding resources and XLarge SAE. Pretrained weights and
abundance preprocessing are unchanged.
