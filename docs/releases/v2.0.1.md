# MGM2 v2.0.1: modular inference and streamlined packaging

MGM2 v2.0.1 brings a clearer Python package, reusable table inference and updated
documentation to Microbial General Model 2.

## Package organization

- Place `mgm2/` directly at the repository root, with dedicated `models`, `data`,
  `inference`, `interpretability` and `training` modules.
- Preserve top-level imports, previous module paths and the `mgm2-embed` command.
- Share one inference pipeline between the Python API and command line.

## Table inference

- Add `embed_table`, `embed_csv` and `save_embeddings` for batch processing and
  model reuse across datasets.
- Preserve lexical feature identifiers such as `001` and `NA`.
- Validate identifiers, abundances and batch sizes before model inference.
- Retain sample order, checkpoint identity and embedding-resolution provenance
  in NumPy archives, with evaluation-mode checks and overwrite protection.

## Documentation and distribution

- Expand installation, development and inference guides.
- Use the official Hugging Face light model badge and hosted Shields.io badges.
- Pin checkpoint links and download examples to the `v2.0.1` model bundle.
- Apply consistent linting and formatting in package CI.

## Validation

The release passes 27 unit and interface tests, source-distribution-to-wheel
installation checks, four README examples and the complete seven-cell notebook.
The four pretrained scales reproduce the original CPU FP32 hidden states, CLS
representations, semantic projections and reconstruction outputs exactly on the
checked real-data batches.

This code and documentation release uses the same pretrained weights and
embedding resources as v2.0.0. The v2.0.0 release remains available.
